# Chat Card Sizer

Foundry VTT module (v13–v14, dnd5e 5.0+) that lets each player adjust chat card font size and the size of the attack/damage/save buttons and their icons. Settings are per player (client scope).

## Install

In Foundry: **Add-on Modules → Install Module**, paste this manifest URL:

```
https://raw.githubusercontent.com/siller94-art/chat-card-sizer/main/module.json
```

Then enable it in your world and open **Configure Settings → Chat Card Sizer**.
